Salut, moi c'est Gnimdou, développeur frontend basé à Lomé. Ce blog est l'endroit où je partage ce que j'apprends en construisant des produits réels.

## Pourquoi un blog ?

Écrire m'oblige à comprendre vraiment ce que je fais. Quand une solution marche, je veux pouvoir expliquer **pourquoi** elle marche. Et si ces notes peuvent faire gagner du temps à quelqu'un d'autre, c'est encore mieux.

## Ce que vous trouverez ici

- **Frontend** : React, Angular, animations et interfaces soignées.
- **Backend et API** : Django REST Framework et Spring Boot, du point de vue de quelqu'un qui consomme ces API côté interface.
- **Mobile** : mes expériences avec Flutter.
- **Coulisses de projets** : ce qui a marché et ce que je ferais autrement sur des projets comme DigitalTaxe, AGRI_LINK ou Economiz+.
- **Freelance** : comprendre le besoin d'un client, estimer, livrer.

## Un petit avant-goût

Une habitude simple que j'applique partout : respecter les préférences d'animation de l'utilisateur.

```tsx
const reduce = window.matchMedia("(prefers-reduced-motion: reduce)").matches;

if (!reduce) {
  startAnimation();
}
```

Une ligne de plus, et le site reste agréable pour tout le monde.
